About Our Project

Our project is a Dictionary Application. Its main goal is to let anyone type an English word and instantly see its definitions, phonetic spelling, example sentences and synonyms.

The app uses JavaScript fetch() with async/await to get data from a public API, and shows friendly messages when something goes wrong.

  • Type: Dictionary Application
  • API: FreeDictionaryAPI.com
  • Built with: HTML, CSS, JavaScript
